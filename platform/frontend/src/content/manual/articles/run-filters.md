# 筛选与同口径趋势

筛选只改变你查看哪些历史记录，不会改运行、切换目标或执行测试。

## ID、名称、地址不要混填 {#ids}

环境ID、目标ID、场景ID分别来自对应配置/资产目录；不是显示名称或域名。先在记录快照核实ID，筛选才能找到正确结果。

## 固定维度再比变化 {#compare-scope}

趋势比较需要环境、模式、场景、发布版本，避免把不同测试定义混成一条曲线。构建筛选进一步限定被测业务版本；开始结束时间必须明确时区。

查询为空可能是ID或维度不匹配，也可能确实没有记录。先清空条件逐项加入，不用新建一次真实运行来“凑出数据”。

## 带时区时间 {#iso-time}

明确绝对时间和时区，避免北京时间与UTC差8小时。

**在哪里使用：** 结果时间筛选/隔离到期 → 带时区ISO时间。

**填写或阅读示例：** `2026-10-27T09:00:00+08:00`。

**应该看到什么：** 查询窗口或到期点按明确瞬间解释。

**常见错误：** 填无时区文本，或只填09:00。

## 固定维度趋势 {#trend}

同环境、执行模式、场景和发布版本才可比较。

**在哪里使用：** 结果 → 固定维度趋势。

**填写或阅读示例：** 选env-test、live、实际场景ID和v1。

**应该看到什么：** 缺维度按钮禁用，完整后展示相同口径。

**常见错误：** 混v1/v2或模拟和真实做质量趋势。

## 按环境 ID 筛选 {#filter-environment}

筛环境对应记录，不改请求地址。

**在哪里使用：** 结果筛选 → 环境ID。

**填写或阅读示例：** 填环境目录实际ID，空表示不限。

**应该看到什么：** 只展示匹配运行。

**常见错误：** 填“测试环境”名称代ID。

## 按目标 ID 筛选 {#filter-target}

按被测服务配置标识筛选。

**在哪里使用：** 结果筛选 → 目标ID。

**填写或阅读示例：** 填快照target_id，不是https地址。

**应该看到什么：** 列表限于该目标。

**常见错误：** 以为筛选会把旧run换目标。

## 按场景 ID 筛选 {#filter-scenario}

筛含指定场景的运行，可配固定版本。

**在哪里使用：** 结果筛选 → 场景ID。

**填写或阅读示例：** 填资产真实ID。

**应该看到什么：** 追踪同一场景历史。

**常见错误：** 场景名称代ID，或以为添加到套件。

## 按场景发布版本筛选 {#filter-version}

限制历史使用的固定发布版本，不是修订号。

**在哪里使用：** 结果筛选 → 场景发布版本。

**填写或阅读示例：** 场景ID配version=2。

**应该看到什么：** 只看该版本运行。

**常见错误：** 填r2或以为改变旧run版本。

## 按被测构建筛选 {#filter-build}

匹配运行已记录业务构建。

**在哪里使用：** 结果筛选 → 被测构建。

**填写或阅读示例：** 实际SHA或镜像标识。

**应该看到什么：** 不把其他构建成功混入。

**常见错误：** 输入后认为补齐旧记录未知build。
