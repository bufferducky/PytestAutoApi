# 请求字段：地址、参数、请求体

按真实接口契约拆开填写，每部分只承担自己的职责。

## 对照一条查询 {#example}

`GET https://api.example.test/api/customers?page=1` 拆为：目标根地址 `https://api.example.test`；URL `{{host}}/api/customers`；方法GET；查询参数page=1；请求体none。域名是占位，执行前替换真实测试服务。

身份负责自动认证，其他动态业务值用[参数](/manual/parameters#parameters)和[输出提取](/manual/extractors#extractors)；不要每一步手贴会过期的Token。

## HTTP 方法 {#method}

方法由接口规定，不与是否修改数据一一对应。

**在哪里使用：** 步骤 → 方法。

**填写或阅读示例：** 接口是POST查询就选POST，并另确认query用途。

**应该看到什么：** 请求与服务路由一致。

**常见错误：** 查询一律改GET造成405。

## 请求 URL {#url}

目标内具体接口路径，可组合host和已声明模板。

**在哪里使用：** 步骤 → URL。

**填写或阅读示例：** `{{host}}/api/customers/{{outputs.list_customers.id}}`，先有提取和依赖。

**应该看到什么：** 运行替换本次目标和对象ID。

**常见错误：** 错写host、漏括号、引用未定义输出或指向无关域名。

## 业务用途 {#operation}

query声明无副作用，write声明会改数据，影响轮询和重放限制。

**在哪里使用：** 步骤 → 业务用途。

**填写或阅读示例：** 已确认列表query，创建订单write。

**应该看到什么：** 按真实用途执行有限策略。

**常见错误：** 为允许重试把write假标query。

## 请求契约确认 {#contract}

人工记录已有路径、方法、字段、结果和影响范围依据。不是勾选后自动证明正确。

**在哪里使用：** 步骤/登录/资源/旅程 → 契约确认。

**填写或阅读示例：** 先核对真实接口资料再勾选，保留依据。

**应该看到什么：** 预检不再因未确认阻塞，业务仍靠断言。

**常见错误：** 只为绕过错误盲勾。

## 请求头 {#headers}

协议元信息，认证优先用身份自动注入。

**在哪里使用：** 编辑与调试 → 请求头标签页。

**填写或阅读示例：** 需要时Content-Type为application/json，动态值可模板。

**应该看到什么：** 脱敏实际请求中看到头字段。

**常见错误：** 把响应头当请求头，重复贴过期Authorization。

## 查询参数 {#query}

URL问号后的条件，由平台编码拼接。

**在哪里使用：** 编辑与调试 → 参数标签页。

**填写或阅读示例：** 名称page值1；名称keyword值测试。

**应该看到什么：** 实际query有对应键值。

**常见错误：** 同条件又手拼URL又填query。

## 请求体类型 {#body-type}

none不发；json发JSON；form发编码表单；raw发原文。

**在哪里使用：** 编辑与调试 → 请求体标签页 → 请求体类型。

**填写或阅读示例：** 无body的GET选none，约定JSON的POST选json。

**应该看到什么：** 发送编码与服务要求一致。

**常见错误：** 只改文本不改类型，none下仍期待body发送。

## 请求体 {#body}

json/form框填合法JSON；raw按原文，可引用参数和输出。

**在哪里使用：** 编辑与调试 → 请求体标签页。

**填写或阅读示例：** `{"customerId":"{{params.customer_id}}"}`，参数先声明string。

**应该看到什么：** 完整模板保留原值类型。

**常见错误：** 单引号/尾逗号，或写入真实凭证。

## 401 后安全重放 {#replay}

已确认安全query才允许刷新身份后最多重放一次，首次错误保留。

**在哪里使用：** 编辑与调试 → 高级设置 → 401后重放。

**填写或阅读示例：** 确认无副作用列表可启用，写操作不可借此重试。

**应该看到什么：** 诊断保留两次尝试，非无限登录。

**常见错误：** 以为断言失败也重试，或写请求因此安全。
