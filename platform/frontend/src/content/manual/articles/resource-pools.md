# 专属资源池与租约

资源池登记明确可测试的对象，租约说明当前谁能用它。

## 登记与借用 {#register}

扩展工具资源面板登记池：填pool_id、target_id、tenant_id、project_id、精确object_id，并确认专属测试对象。登记不会自动证明业务权限；先核实真实归属、恢复契约和可用性。

lease领取有owner、generation和expires_at，避免并发使用同一对象。到期并不等于对象已恢复，也不会自动给下个run复用；遇到冲突或待对账，先按[清理流程](/manual/cleanup#flow)处理。

## 专属资源池 {#pool}

已登记专属对象集合，lease从中领取，read_only另指精确ID。

**在哪里使用：** fixture → 资源池ID；资源面板 → 登记池。

**填写或阅读示例：** pool_id=`customer-test-pool`，范围与目标项目一致。

**应该看到什么：** 拿到带归属和代次的租约。

**常见错误：** 把普通共享客户全集当可写测试池。

## 精确对象 ID {#object-id}

业务内明确的测试对象标识，不是名称或任意第一条。

**在哪里使用：** 只读精确对象ID/资源池登记对象ID。

**填写或阅读示例：** 填已核实customer-001，read_only还需匹配池记录。

**应该看到什么：** 可追溯这一对象被谁使用。

**常见错误：** 用模糊名称或列表第一条定位。

## 专属测试对象确认 {#dedicated}

确认只用于测试且归属明确、可恢复。勾选不会自动核查业务所有权。

**在哪里使用：** 资源池登记 → 专属测试对象确认。

**填写或阅读示例：** 先拿专用测试清单核实，再确认并登记。

**应该看到什么：** 对象可以按既定策略管理。

**常见错误：** 把生产客户或他人共享数据勾成专属。

## 资源租约状态 {#lease-state}

owner是持有者，generation区分代次，expires_at为期限；状态不是业务恢复结果。

**在哪里使用：** 资源表 → 状态/owner/generation/到期。

**填写或阅读示例：** 看到expired/冲突先对账，不手工强认available。

**应该看到什么：** 通过账本追到所属run和待办。

**常见错误：** 仅凭时间过期就复用或删除。
