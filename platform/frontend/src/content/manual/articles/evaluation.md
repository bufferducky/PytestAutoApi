# 历史AI与语音评估：能看什么

目前只提供历史查询与同口径对比，新评估执行已禁用。

## 查询历史报告 {#steps}

扩展工具 → 历史评估报告 → 刷新历史版本 → 需要时展开样本集和规则 → 填真实历史run ID → 查看报告。新建按钮禁用是当前能力边界，不是漏配某个网页字段。

## 对比的前提 {#comparable}

必须是相同样本集合、规则版本、任务及采样设置，才有可解释的比较。不同集分数不能直接横比；历史模拟/合成机制结果不代表真实业务、真人语音或当前模型质量已经验证。

本手册不提供恢复新执行或付费模型接入步骤。需要的是新评估能力建设时，另行确认真实服务、样本和预算，不通过旧说明绕过禁用。

## 历史质量评估 {#evaluation}

只读历史报告、样本集和规则，新评估未接真实服务而禁用。

**在哪里使用：** 扩展工具 → 历史评估。

**填写或阅读示例：** 填已有评估run ID，查看当时范围和模型标识。

**应该看到什么：** 得到历史详情，不产生新的模型调用。

**常见错误：** 按旧文档找新建评估参数，或把历史分数当当前质量。

## 同口径历史评估对比 {#evaluation-compare}

在同集合、规则和采样条件下对照历史结果。

**在哪里使用：** 历史评估 → 对比run ID。

**填写或阅读示例：** 先选主run，再填可比run，点击同口径对比。

**应该看到什么：** 不符合口径时拒绝，不重新评估。

**常见错误：** 混用不同样本集分数声称提升。
