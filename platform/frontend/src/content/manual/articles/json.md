# JSON：怎么填写对象、数组和值

先学会区分数字、字符串和对象，再填写平台的 JSON 输入框。

## 六种常见值 {#types}

| 类型 | 合法写法 | 用在什么地方 |
| --- | --- | --- |
| 字符串 string | "customer-001" | ID、名字、日期文本 |
| 数字 number | 200 或 12.5 | 业务码、数量、金额（按契约） |
| 布尔 boolean | true 或 false | 是否启用 |
| 空值 null | null | 字段存在但没有值 |
| 对象 object | {"page":1} | 公开参数、请求体 |
| 数组 array | ["a","b"] | ID 列表、断言规则列表 |

字符串两侧必须是英文双引号。`"200"` 和 `200` 类型不同；`"false"` 是一段文字，不是关闭开关。

## 对象和数组怎么读 {#objects-arrays}

```json
{
  "code": 200,
  "data": {
    "records": [{"id":"customer-001","name":"测试客户"}],
    "total": 1
  }
}
```

大括号表示对象，里面按“字段名: 值”排列。中括号表示一组值。`records` 是数组，数组第一个元素的序号是 0。

## 常见写错方式 {#mistakes}

| 错误 | 正确 | 原因 |
| --- | --- | --- |
| {'page':1} | {"page":1} | 单引号不是 JSON |
| {page:1} | {"page":1} | 字段名需要双引号 |
| {"page":1,} | {"page":1} | 末尾不能多逗号 |
| {"enabled":True} | {"enabled":true} | JSON 布尔值是小写 |
| 在公开参数框填 [] | {} 或 {"page":1} | 该框要求对象，不是数组 |

JSON 不能写 `// 注释`。示例旁边的文字解释不要一起粘进输入框。完整断言框要求数组，公开参数框要求对象，要看字段标题而不是一律粘 `{}`。

## 模板为什么看起来像字符串 {#templates}

请求体中可填写 `{"page":"{{params.page}}"}`。当一个字符串完整地是一个模板占位时，执行器会保留引用值的原始类型；参数 page 为数字 1 时，实际 body 里会得到数字 1。混合文本如 `"page-{{params.page}}"` 则会变成字符串。详见[参数](/manual/parameters#parameters)。
