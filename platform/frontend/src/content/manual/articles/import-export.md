# 导入、导出与迁移

> 当前界面入口：用例工作区的“接入与高级”集中提供业务回归包、已有资产导入和迁移元数据；脱敏导出在“正式运行”中按选中的发布版本查看。

旧定义转成草稿后仍需核对真实契约，导入成功不是测试通过。

## 迁移顺序 {#flow}

导入YAML/标准JSON → 阅读报告 → 补目标身份与契约 → 保存预检 → 发布 → 计划 → 真实运行。导入只创建定义，不立即请求业务。

缺契约和不支持字段可成为阻塞项，删掉文字不代表能力已补全。导出含公开内容与秘密引用，脱敏占位无法恢复已经撤销的密码。

## 导入资产 {#import}

转旧YAML或标准发布JSON为可编辑草稿，保留迁移报告并移除旧秘密值。

**在哪里使用：** 资产 → 迁移已有资产。

**填写或阅读示例：** 选择类型，粘贴公开定义，导入后检查报告。

**应该看到什么：** 新草稿可编辑，没有自动发布或运行。

**常见错误：** 认为旧语法全部无损支持。

## 脱敏导出 {#export}

公开固定定义用于审查/迁移，不导出真实秘密。

**在哪里使用：** 已选发布版本 → 查看脱敏导出。

**填写或阅读示例：** 选v1检查公开配置及引用。

**应该看到什么：** 可追溯发布内容，而不是获得可用账号。

**常见错误：** 把脱敏占位重新当密码。

## 迁移与扩展元数据 {#migration}

保留来源、警告、阻塞项和资源声明，发布按消费者检查。

**在哪里使用：** 高级元数据/迁移信息。

**填写或阅读示例：** 核对source、migration_warnings、migration_blockers、fixtures。

**应该看到什么：** 未知处明确保留，补依据后处理。

**常见错误：** 清空blocker假装确认，或加无执行消费者字段。
