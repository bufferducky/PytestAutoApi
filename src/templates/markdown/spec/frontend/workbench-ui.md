# 工作台交互与视觉约束

作用域：`platform/frontend/`。修改六个页面、资产编辑器或公共控件时读取；几何边界和视口集合见 [responsive-layout.md](./responsive-layout.md)。

## 公共样式的归属

- `styles/variables.css` 定义浅色工作台的颜色、字体、圆角和阴影；`base.css` 定义按钮、字段、fieldset、table、details、状态提示与可见焦点。
- 页面使用 `PlaceholderPanel`、`MetricCard`、`StatusTag` 与 `action-button` 变体。普通操作使用有边框按钮；保存/提交使用主按钮；归档/删除使用危险变体。
- `SideNav` 保留六个主导航与 `aria-current`；桌面侧栏占视口高度，品牌和菜单按内容分配，footer 靠下。1080px 以下使用顶部导航，540px 以下为三列两行。
- 两列表单的 label 使用 `align-content:start`，避免同一行 textarea 把相邻 input 拉高。checkbox/radio 保持独立尺寸。

## 信息层级

- AppHeader 的路由 meta 负责标题和一句用途说明。执行方式、个人使用等常量不做重复统计卡。
- 资产编辑器按基本信息、执行上下文、请求步骤、保存预检、发布、固定版本运行分组。目标、URL、请求方法和主要断言可直接编辑；请求选项、参数 schema、变量提取、高级断言、导入迁移和原始证据使用 details。
- 折叠只改变可见性，保留 v-model、默认值、序列化字段与 API 路径。必填字段保持可见，或在提交校验前展开对应区域。
- 产品文案解释当前操作与结果；开发阶段、组件状态管理、实现计划写进开发文档。真实请求、模拟历史、构建未知和发布证据的边界继续明确展示。

## 资产列表与编辑状态

`ScenarioAssetsPanel` 的搜索只过滤当前 assets 的名称、ID 和标签，大小写不敏感；它不修改 selected 或持久化数据。无数据和无搜索结果分别提示，搜索空态提供清空入口。

| 操作 | 行为 |
|---|---|
| 首次读取，已有资产且表单无修改 | 选择第一条并读取其发布版本 |
| 首次读取，用户已输入 | 保留输入 |
| 新建或选择另一资产，有未保存修改 | 确认放弃；取消后保留所有输入 |
| 点击当前选中项 | 保持当前编辑内容 |
| 搜索隐藏当前选中项 | 编辑内容继续保留 |
| API 读取/选择失败 | 显示错误，保留错误含义，不填充演示结果 |

选中按钮同时使用 `asset-list__item--selected` 与 `aria-pressed`。异步操作禁用冲突操作；错误用 role=alert，成功消息用 role=status。初始 savedDraft 快照必须与默认表单一致，避免空白草稿被误判成已修改。

## 浏览器验收

复用 `tests/backend/test_platform_frontend_browser.py` 的隔离本地 API；生产构建后实际操作表单：

1. 空资产 → 创建 → 保存 → 搜索无结果/清空 → 取消放弃未保存编辑 → 预检 → 发布 → 运行 → 诊断。
2. 创建引用该场景固定版本的套件，保存后检查选中态。
3. 六路由 × 九宽度，等待已保存资产和非空运行出现；分别检查默认与展开高级面板后的布局。
4. 截图前回到页首，另行检查高级区域。只检查关闭状态会漏掉表单/证据溢出。
5. 断开 API 后保留显式错误，无演示数据兜底。

## 就地帮助（问号提示）

- 非直观字段、统计口径、状态和有副作用的操作使用 `common/HelpHint.vue`，通过类型化 `topic` 显式关联 `content/helpTopics.ts`。同一概念共用文案；明显的名称/刷新/分页保持简洁。
- 文案说明用途、适用条件、可选值/示例和操作影响；预检、保存、发布、运行、清理分别解释，真实/模拟/未验证与发布许可按当前业务契约区分。
- 字段标题与问号放在 `.field-caption`；原控件保留明确 `aria-label`。带帮助的静态标题、表头和 summary 保留原可访问名称，帮助按钮使用“查看帮助：主题”，避免改变业务控件名称或匹配到已有字段定位器。
- 帮助触发器始终 `type=button`，点击阻止冒泡和默认行为；操作旁问号作为 `.action-help` 中的兄弟节点，不能嵌套进原操作按钮。禁用原操作时仍可阅读问号。
- 悬停/键盘聚焦显示，移出延迟关闭，允许移入说明阅读；点击固定，重复点击/外部点击/Escape 关闭。点击 label 或 summary 内的问号不切换勾选或折叠，不提交表单。
- 浮层 Teleport 到 body，限制宽高并按锚点避让视口边缘。滚动时跟随可见锚点，锚点离开视口或组件卸载时关闭并移除监听；浮层自身滚动保持可读。
- `action-help` 作为表单 Grid 子项时按操作行底部对齐，避免原按钮与问号分离；状态标签和问号同组，避免 Flex 的 space-between 把问号推远。

验收复用真实浏览器测试：悬停后可移入说明、键盘焦点关联 `aria-describedby`、Escape 关闭、手机点击开关/外部关闭；问号点击不产生 POST/PATCH/DELETE，不切换勾选/summary。六路由九宽度打开实际浮层验证四边界，再验证默认/高级面板两状态布局。问号增宽可能暴露原始表格最小宽度，宽表继续放 `.table-shell`，不能裁切整页。
