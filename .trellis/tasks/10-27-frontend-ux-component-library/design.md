# 设计：围绕测试任务重建桌面工作区

状态：用户批准后已完成实现与本地验收。需求及验收以 [PRD](./prd.md) 为准；实际证据见 docs/reviews/2026-10-27-frontend-ux/README.md。

## 组件库和视觉基础

采用 Element Plus，应用根配置中文 locale。`styles/variables.css` 保留业务语义 token 并映射库主色、字体、圆角和边框；正文默认 14px，常用控件统一 32/36px 密度。`base.css` 负责 reset、页面和正文排版，旧原生控件规则收窄到尚未迁移或正文范围，避免影响库内部 DOM。

通过一致的显式导入/按需机制加载实际用到的组件和样式，不安装两套同类库，不仅包外围卡片。接入时检查实际 Vue/Vite/TypeScript 组合、CSS 顺序和弹层定位。手册及 Mermaid 继续延迟加载。

| 能力 | 组件方向 | 约束 |
| --- | --- | --- |
| 导航、页内任务和工具 | Menu、Tabs、Breadcrumb | 保留路由、aria-current、深链接；避免重复大标题 |
| 表单与目录选择 | Form/FormItem、Input、Select、Checkbox、Switch、TimePicker | 明确标签、名称检索、空态和错误；字段类型及版本号不漂移 |
| 列表与状态 | Table、Tag、Pagination、Descriptions | 键盘选中、真实分页来源和历史状态 |
| 反馈与确认 | Alert、Message、Dialog/MessageBox、Skeleton、Empty | 长错误留页面；取消不写接口；明确当前对象/全局范围 |
| 代码与证据 | 公共证据区、Input textarea、既有结构化编辑器 | 局部滚动、格式错误、复制脱敏内容；保留原始记录 |
| 帮助 | 保留 HelpHint 契约并统一主题 | 交互说明、手册新标签、键盘和不冒泡优先，不盲换纯 tooltip |

## 用例工作区

```text
全局侧栏 | 紧凑页头 / 当前场景 / 草稿状态
         | 场景与步骤目录 | 编辑与调试 / 场景设置 / 发布与版本 / 正式运行
         | 搜索场景       | 步骤名称、方法、URL          保存 / 调试
         | 当前场景步骤   | 参数 / 请求头 / 请求体 / 断言 / 提取 / 高级
         | 新增、排序     | 当前分区编辑
         |               | 调试范围与状态 / 响应 / 断言 / 提取 / 原始证据
```

这是布局约束草图，不是假定已实现的原型。1280px 编辑和结果上下布局，1920px 可分配更多并排空间；场景和步骤有明确层级，不再添加多个独立宽侧栏。工具栏固定可达，下拉、帮助和对话框不被父容器裁切。

- 只显示当前步骤视图，全部步骤模型在工作区持有。切标签/步骤只改变视图，非法 JSON 文本也保持。
- 新场景先显示名称/目标等必要信息；已有场景默认编辑请求，场景设置有明显独立入口。
- 参数/头/体/断言/提取一次可达；稳定 ID、阶段、依赖、重放、等待和高级断言有具名分区。执行前保留必要约束和范围确认。
- 保存和调试独立；显示单步/整场景、环境及快照范围；发布和正式运行不要求滚过步骤。
- 预检先显示通过/失败和可定位问题，原始结果可展开；发布说明、版本列表及不可变关系清楚。
- 正式运行单独选择版本、环境、构建及参数，计划预览先给范围结论再确认，跳转对应 runId。

## 模块与数据边界

现有 ScenarioAssetsPanel 同时承担目录、编辑、序列化、发布、运行、导入和保护，按职责逐步抽取，避免重复状态：

- 资产工作区持有 kind、selected、revision、savedDraft、dirty、所有步骤缓冲及 saved/selected 事件；API 模型与 UI 缓冲转换在一个边界完成。
- 步骤目录接收显示项和选中 key，发出选择/新增/复制/移动/删除；选中 key 使用稳定内部标识，不用可编辑 step_id 或数组下标作为组件身份。
- 请求编辑区接收当前步骤及字段错误，不私自重载后端覆盖其他步骤。
- 发布运行区仅使用已保存资产及固定版本，不能拿未保存编辑替代发布内容。
- 统一校验返回 asset/stepKey/section/field/message，校验完整模型后切到错误位置并 nextTick 聚焦；保存与调试复用同一校验/序列化链。
- 复用 AssertionEditor、ExtractorEditor、EnvironmentVariablesEditor、RunStepEvidence 等业务表达，迁移通用控件；扩展键和类型保留。

### 状态与异步确认

1. 编辑缓冲、保存草稿、发布版本和调试快照独立；浏览器持久化仅记最近资产 ID，不保存请求/凭证。
2. 确认返回 Promise，取消是正常结果；等待时锁冲突动作，捕获 ID/revision/步骤/generation，结束后重新检查作用域。
3. 调试发送用户确认的快照，不能在确认后读取期间变化的编辑值。异步弹窗替代同步 confirm 后独立回归该行为。
4. 切对象/路由统一异步丢弃确认，取消保留输入及选中态；刷新/关闭仍用 beforeunload，正式提交后的程序跳转显式放行。
5. 读请求保留序号/generation，失败保留数据并提示过期；后台暂停轮询、卸载清理保持。

## 页面交互和功能保留

| 页面 | 新主线 | 原能力保留 |
| --- | --- | --- |
| 工作台 | 紧凑快捷操作、最近资产、失败与运行直达 | 真实统计、调试/历史标识、独立失败查询 |
| 用例 | 目录→当前步骤→就近调试；设置/发布/运行分区 | 接诊回归包、数据源预检、YAML/JSON 导入、脱敏导出、迁移元数据 |
| 套件 | 主目录→固定场景引用→发布/运行 | 版本核验、顺序/预算、缺失错误、不可变版本 |
| 环境 | 环境/目标/身份/绑定标签→目录→表单 | 变量类型、登录、秘密引用、归属预检、高级公开 JSON |
| 结果 | 常用筛选→列表→就近详情 | 趋势、原始快照、清理、保留回收、重跑/取消 |
| 调度 | 计划目录→编辑/触发记录 | Cron/时区/预览、发布摘要、状态及全局暂停 |
| 扩展 | 四类导航与用途→工具内容 | 全部工具及历史评估只读限制 |
| 手册 | 搜索/目录/正文分区与阅读宽度 | 稳定地址、Mermaid、表格/代码、问号精确新标签页 |

详情允许内部滚动，重点是选中对象和主操作持续可见；宽证据局部横滚。没有后端全量检索时如实标明当前页过滤。

## 兼容与迁移风险

- API 路径、字段类型、顺序、extras、固定引用和凭证引用语义不变，不做数据库迁移。
- 保持 cases/suites 的 assetId、runs 的 runId、manual 的文章/小节深链接；新增视图状态使用兼容 query 或本地 UI 状态。
- 重点验证原 CSS、HelpHint、Select、Dialog、Message 的层叠、焦点和可访问性。
- 可靠性 harness 适配库导入和异步确认，保留业务断言；浏览器走真实库下拉/弹窗，不绕过交互伪造成功。
- 不 reset/clean 用户工作区，不自动提交或部署；仅在本任务增量中修正失败。

具体验证见 [实施计划](./implement.md)。安装库、改壳层或构建通过均不能单独证明全量体验完成。
