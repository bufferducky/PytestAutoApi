# 工作台交互与视觉约束

## 个人接口工作台（2026-10-27）

- 六个业务主导航保留，新增“使用手册”入口，覆盖/资源/Web-App/历史评估在 `/extensions`；辅助能力不删除。首页显示真实最近资产、失败入口与运行，调试明确标记。
- 已保存资产默认进入编辑/编排，新建进入设置。工作区一次只显示当前步骤，所有步骤缓冲仍由资产工作区持有；保存与调试先校验完整模型，错误定位步骤、请求标签页及字段。不得只依赖当前已挂载的原生必填校验。
- 编辑缓冲、已保存草稿和调试快照独立；`ScenarioAssetsPanel` 的 saved({id}) 同步目录，selected(assetId) 记忆非敏感最近资产 ID，不能把请求或凭证写入 localStorage。
- 调试直接发送当前编辑值，显式确认范围；缺前置输入阻止，结果结构化展示。资产/步骤切换重置或明确标记旧结果，请求序号阻止旧响应覆盖，后台暂停轮询、恢复刷新。
- 未保存保护覆盖切资产、切路由和刷新；正式运行跳转使用显式放行。新建/取消处理器不能把 Vue MouseEvent 当作 force 参数绕过保护；内部强制重置和用户确认入口分开。
- 环境变量结构化和高级 JSON 保留类型，非法输入不允许保存；调度套件/环境/版本通过真实目录选择，新建完整重置，时间规则最终产生明确 cron/timezone，预览不发送业务请求。
- UiSelect 使用真实 ElSelect/ElOption，保留明确 aria-label、值类型、多选及可检索选项。测试操作实际下拉选项；多选点击可见 wrapper，键盘 Escape 收起，不调用原生 select_option 绕过真实交互。

作用域：`platform/frontend/`。修改六个页面、资产编辑器或公共控件时读取；几何边界和视口集合见 [responsive-layout.md](./responsive-layout.md)。

## 公共样式的归属

- `styles/variables.css` 定义浅色工作台的颜色、字体、圆角和阴影；`base.css` 定义按钮、字段、fieldset、table、details、状态提示与可见焦点。
- 页面使用 `ContentPanel`、`MetricCard`、`StatusTag` 与 `action-button` 变体。普通操作使用有边框按钮；保存/提交使用主按钮；归档/删除使用危险变体。
- `SideNav` 保留六个业务入口和“使用手册”共七个主导航及 `aria-current`；桌面侧栏占视口高度，品牌和菜单按内容分配，footer 靠下。后续不再要求手机兼容，桌面范围见 responsive-layout.md。
- 两列表单的 label 使用 `align-content:start`，避免同一行 textarea 把相邻 input 拉高。checkbox/radio 保持独立尺寸。

## 信息层级

- AppHeader 的路由 meta 负责标题和一句用途说明。执行方式、个人使用等常量不做重复统计卡。
- 资产工作区按编辑/编排、设置、发布与版本、正式运行、接入与高级分区。当前步骤方法/URL 常显，参数、头、体、断言、提取、高级设置用一层具名标签；原始 JSON、参数 schema、迁移和证据可以展开。套件不显示无内容的场景接入标签。
- 折叠只改变可见性，保留 v-model、默认值、序列化字段与 API 路径。必填字段保持可见，或在提交校验前展开对应区域。
- 产品文案解释当前操作与结果；开发阶段、组件状态管理、实现计划写进开发文档。真实请求、模拟历史、构建未知和发布证据的边界继续明确展示。

## 资产列表与编辑状态

`ScenarioAssetsPanel` 的搜索只过滤当前 assets 的名称、ID 和标签，大小写不敏感；它不修改 selected 或持久化数据。无数据和无搜索结果分别提示，搜索空态提供清空入口。

| 操作 | 行为 |
|---|---|
| 首次读取，已有资产且表单无修改 | 选择第一条并读取其发布版本 |
| 首次读取，用户已输入 | 保留输入 |
| 新建或选择另一资产，有未保存修改 | 确认放弃；取消后保留所有输入 |
| 点击当前选中项 | 保持当前编辑内容 |
| 搜索隐藏当前选中项 | 编辑内容继续保留 |
| API 读取/选择失败 | 显示错误，保留错误含义，不填充演示结果 |

选中按钮同时使用 `asset-list__item--selected` 与 `aria-pressed`。异步操作禁用冲突操作；错误用 role=alert，成功消息用 role=status。初始 savedDraft 快照必须与默认表单一致，避免空白草稿被误判成已修改。

## 浏览器验收

复用 `tests/backend/test_platform_frontend_browser.py` 的隔离本地 API；生产构建后实际操作表单：

1. 空资产 → 创建 → 保存 → 搜索无结果/清空 → 取消放弃未保存编辑 → 预检 → 发布 → 运行 → 诊断。
2. 创建引用该场景固定版本的套件，保存后检查选中态。
3. 六个业务路由、扩展工具及手册 × 三个桌面宽度，等待已保存资产和非空运行出现；分别检查默认与展开高级面板后的布局。
4. 截图前回到页首，另行检查高级区域。只检查关闭状态会漏掉表单/证据溢出。
5. 断开 API 后保留显式错误，无演示数据兜底。

## 就地帮助（问号提示）

- 非直观字段、统计口径、状态和有副作用的操作使用 `common/HelpHint.vue`，通过类型化 `topic` 显式关联 `content/helpTopics.ts`。同一概念共用文案；明显的名称/刷新/分页保持简洁。
- 文案说明用途、适用条件、可选值/示例和操作影响；预检、保存、发布、运行、清理分别解释，真实/模拟/未验证与发布许可按当前业务契约区分。
- 字段标题与问号放在 `.field-caption`；原控件保留明确 `aria-label`。带帮助的静态标题、表头和 summary 保留原可访问名称，帮助按钮使用“查看帮助：主题”，避免改变业务控件名称或匹配到已有字段定位器。
- 帮助触发器始终 `type=button`，点击阻止冒泡和默认行为；操作旁问号作为 `.action-help` 中的兄弟节点，不能嵌套进原操作按钮。禁用原操作时仍可阅读问号。
- 悬停/键盘聚焦显示，移出延迟关闭，允许移入说明阅读；点击固定，重复点击/外部点击/Escape 关闭。点击 label 或 summary 内的问号不切换勾选或折叠，不提交表单。
- 浮层 Teleport 到 body，限制宽高并按锚点避让视口边缘。滚动时跟随可见锚点，锚点离开视口或组件卸载时关闭并移除监听；浮层自身滚动保持可读。
- `action-help` 作为表单 Grid 子项时按操作行底部对齐，避免原按钮与问号分离；状态标签和问号同组，避免 Flex 的 space-between 把问号推远。

验收复用真实浏览器测试：悬停后可移入说明、键盘焦点关联 `aria-describedby`、Escape 和外部点击关闭；问号点击不产生 POST/PATCH/DELETE，不切换勾选/summary。按桌面宽度打开实际浮层验证四边界，再验证默认/高级面板两状态布局。帮助中的“查看完整手册”在新标签页精确定位，原编辑页的 URL、输入和未保存状态不变；按钮与弹层之间的焦点转移不能关闭链接。问号增宽可能暴露原始表格最小宽度，宽表继续放 `.table-shell`，不能裁切整页。

## Element Plus 交互边界（2026-10-27）

- `main.ts` 显式注册实际使用的库组件，`App.vue` 配置中文 locale。variables.css 映射主题；base.css 原生控件规则排除库内部 class，原生帮助按钮规则使用低特异性的 :where，不能压过 HelpHint 自身尺寸/焦点样式。
- `UiInput` 的 update:modelValue 保留 .number 类型，input/change 通过 Event 边界传给既有编辑器；`UiSelect` 从原 option 声明生成 ElOption，真实值不等于显示文本。required 校验代理不能代替完整资产模型验证。
- `confirmAction(message,title?) -> Promise<boolean>`：取消/关闭返回 false，并阻止同时发起多个确认。异步确认前冻结调试草稿、环境、构建和参数；确认后检查作用域/generation，迟到确认不得作用新对象。
- 标签页只改变视图，不重置编辑缓冲；单步骤调试与当前编辑步骤不一致时关闭旧调试区，已有结果明确提示来自上次快照。发布/正式运行始终引用已保存版本。
- 每次显示 HelpHint 时发送 `testflow:help-open`，其他已打开帮助立即关闭；保留移入阅读、手册键盘链路和卸载监听清理。
- ElSelect 自身下拉也可能使用 tooltip role，测试应定位 `.help-tooltip [role="tooltip"]`，不能把任意库浮层都当业务帮助。
- 截图使用 animations=disabled，避免把标签和标签页的入场动画当成视觉缺陷；同时实际操作检查，不能靠截图禁动画掩盖布局问题。
- 运行列表 API 不支持关键词参数，当前关键词查找只过滤本页。时间筛选仍转换成带时区 ISO；不改变后端契约。

真实浏览器额外回归在 `tests/backend/frontend_ux_browser_support.py`：三资产各三步、隐藏错误定位、编辑/复制/排序/删除、类型与 metadata 往返、身份多选、配置分类取消及扩展工具。可靠性脚本另验证异步确认快照和取消不发送请求。


## 运行阅读与搜索（2026-10-28）
- 名称使用后端冻结快照返回的 name；不把资产 ID 当标题。列表与详情最多两行，title 保留完整文字；状态列独立固定宽度。
- `run_number` 以字符串适配为 runNumber，显示 #编号；本页查找覆盖名称、编号（含 # 前缀）、原 ID 与环境。不得转换为 Number 或用分页行号代替编号。
- 长错误/断言通过 EvidenceValue 折叠完整内容，数据库集合差异优先显示缺失/多出/重复数量。展开区域保留全部原始脱敏证据并局部滚动。
- 环境 auth_mode 的 value 与 label 分离，password/none 使用中文标签；历史中文或未知描述保留原值，不在展示层改变鉴权语义。

编号存储、历史补号及 API 契约见 [运行展示契约](../backend/run-display-contracts.md)。
